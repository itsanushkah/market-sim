# Report outline (maps to the grading rubric)

## 1. Problem and why multi-agent (20 pts)
- Price discovery with private, distributed information. No single agent knows supply and demand.
- Why multi-agent: information is decentralized by construction; coordination happens through prices + messages.
- Research questions:
  1. Do LLM traders reach competitive equilibrium? How do they compare to ZI traders?
  2. Which coordination mechanisms matter (analyst consensus, memory, chat)?
  3. Decentralized LLM agents vs one centralized LLM with full information: quality and cost.
- Figure: supply_demand_symmetric.png

## 2. Design and implementation (20 pts)
- Architecture diagram: traders → bus (beliefs, chat) → analyst → bus (analyst) → traders; traders → order book → trades.
- Agent roles: LLM trader (persona, memory, structured JSON action), analyst (aggregates disagreeing beliefs),
  ZI traders, centralized planner.
- Collaboration protocol: per-round simultaneous decisions, random arrival order, CDA matching rules.
- Disagreement resolution: beliefs channel → analyst consensus (median blend; LLM variant), spread reported.
- Optimization: caching, parallel calls per round, structured outputs (no parse failures), effort level,
  model choice; ablations show which components earn their cost.
- Implementation details: budget-constraint enforcement, error handling (agent passes), reproducibility via seeds.

## 3. Evaluation (20 pts)
- Dataset: hand-built symmetric & asymmetric markets, shock market, randomly generated markets (seeded).
- Metrics: efficiency, price RMSD, Smith's alpha, in-band share, extramarginal trades, clip rate, $ cost.
- Baselines: ZI-C, ZI-U, oracle, centralized LLM.
- Results table: results/summary.csv (mean ± 95% CI over seeds).
- Figures: efficiency_by_condition, rmsd_by_condition, price_paths_*, cost_vs_efficiency.
- Qualitative: excerpts from messages.jsonl / orders.jsonl reasoning (e.g. chat collusion, fairness bias in asymmetric market).
